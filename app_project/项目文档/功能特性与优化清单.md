# 中医处方系统 — 功能特性与优化清单

> 更新日期：2026-06-28
> 适用版本：三端统一架构（手机 APP / 桌面端 / 网页端）

---

## 一、项目整体架构

### 1.1 三端统一架构

| 端 | 技术栈 | 离线能力 | 数据存储 |
|---|---|---|---|
| 手机 APP | Capacitor + WebView + Android | SQLite（@capacitor-community/sqlite） | 本地 SQLite + 云端 KV |
| 桌面端 | Electron + better-sqlite3 | SQLite（better-sqlite3） | 本地 SQLite + 云端 KV |
| 网页端 | 纯 HTML/JS | 无离线能力 | 云端 KV（Cloudflare Pages） |

### 1.2 云端服务

- **平台**：Cloudflare Pages + Functions + KV
- **域名**：`https://tcm-prescription-system.pages.dev`
- **数据存储**：Cloudflare KV（键值对存储，按诊所分区）
- **认证方式**：HTTP Basic Auth（`username:role` Base64 编码）

### 1.3 多诊所三级角色体系

| 角色 | role 值 | 权限 |
|---|---|---|
| 平台总管理员 | `platform_admin` | 管理所有诊所，不参与处方业务 |
| 诊所管理员 | `clinic_admin` | 管理本诊所用户/药品/处方查阅 |
| 普通医师 | `doctor` | 仅自己的处方/药品只读 |

### 1.4 用户模式（allowedMode）

| 模式 | 值 | 说明 |
|---|---|---|
| 双模式 | `both` | 在线+离线，数据双向同步 |
| 仅离线 | `local` | 仅本地 SQLite，不访问云端 |

- 新建普通医师默认 `local`
- 管理员默认 `both`
- 管理员可通过"开通云端"切换为 `both`

## 六、文件结构说明

```
统一构建/
├── 项目文档/
│   └── 功能特性与优化清单.md        ← 本文件
├── android/                          ← Android APP 源码
│   ├── app/
│   │   ├── build.gradle              ← versionCode/versionName 配置
│   │   ├── src/main/java/com/tcm/prescription/
│   │   │   └── MainActivity.java     ← WebView 配置 + 安全策略
│   │   └── src/main/AndroidManifest.xml
│   └── variables.gradle              ← SDK 版本配置
├── 打包-云端版/                      ← 桌面端 + 网页端
│   ├── index.html                    ← 前端核心（三端共用）
│   ├── xlsx.full.min.js              ← Excel 导入库
│   ├── electron/
│   │   ├── main.js                   ← Electron 主进程（IPC + 安全）
│   │   ├── preload.js                ← Electron 预加载（contextBridge）
│   │   └── login.html                ← 登录界面
│   ├── package.json                  ← Electron 依赖
│   ├── build.bat                     ← 打包脚本
│   └── 一键打包.bat                  ← 一键打包
```

### 6.1 三端共用的文件

| 文件 | 用途 | 同步策略 |
|---|---|---|
| `index.html` | 前端核心代码 | 修改后同步到 4 个位置 |
| `xlsx.full.min.js` | Excel 导入库 | 很少修改 |

### 6.2 index.html 同步位置

1. `tcm-prescription-system/index.html` ← 源文件（Git 仓库）
2. `统一构建/打包-云端版/index.html` ← 桌面端打包用
3. `public/index.html` ← Cloudflare Pages 部署用
4. `tcm-prescription-pro/version-cloud/index.html` ← 备份

### 6.3 版本号同步

修改 `__APP_VERSION__`（index.html）时必须同步修改 `EXPECTED_APP_VERSION`（MainActivity.java），然后重新编译 APK。

| 位置 | 字段 | 当前值 |
|---|---|---|
| index.html | `__APP_VERSION__` | `2026-06-27-v1` |
| MainActivity.java | `EXPECTED_APP_VERSION` | `2026-06-27-v1` |

## 七、调试技巧

### 7.1 启用调试日志

| 端 | 方法 |
|---|---|
| 网页端 | URL 加 `?debug`，如 `https://tcm-prescription-system.pages.dev/?debug` |
| 桌面端 | index.html script 开头改 `isDebug = true` |
| APP 端 | adb logcat 查看 WebView 控制台 |

### 7.2 常见问题排查

| 问题 | 排查方法 |
|---|---|
| 同步卡死 | 检查 `_fetchWithTimeout` 30秒超时 + `Promise.race` 60秒超时 |
| 处方编号重复 | 检查 `generateClinicGlobalSeq` KV 键 `clinic:{id}:prescription_seq:{yymmdd}` |
| 状态栏显示错误 | 检查 `getAllowedMode()` + `_cloudReachable` + `navigator.onLine` |
| APP 闪屏 | 检查 `reloadKey` 是否用了 `url.split("?")[0]` 去掉时间戳 |
| 医师姓名不对 | 检查登录后 `defaultDoctor.value` 是否立即设置 |
