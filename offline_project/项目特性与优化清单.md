# offline_project - 离线版本项目特性与优化清单

> 更新日期：2026-07-16
> 适用范围：`offline_project/` 下的三个离线版本（本地版/定制版/个人版）

---

## 一、项目概览

### 1.1 三个离线版本对比

| 版本 | 目录 | edition | 产品名称 | 特点 |
|---|---|---|---|---|
| **本地版** | `db-bendi` | `local` | 惠康中医诊所管理系统-本地 | 完整功能，多用户，可编辑诊所名称 |
| **定制版** | `db-dingzhi` | `custom` | 惠康中医诊所管理系统-定制 | 诊所名称只读，单管理员，月度报表 |
| **个人版** | `db-geren` | `personal` | 惠康中医诊所管理系统-个人 | 诊所名称/医师姓名都只读，固定用户名 |

### 1.2 共享代码层

`_shared/` 目录存放三版本完全相同的 JS 模块，通过 `sync-all.bat` 一键同步到三个版本：

| 文件 | 用途 |
|---|---|
| `auth-core.js` | 用户认证核心 |
| `db-adapter.js` | 数据库适配层 |
| `prescription-core.js` | 处方核心逻辑 |
| `patient-archive.js` | 患者档案管理 |
| `medicine-dict.js` | 药品字典 |
| `print-utils.js` | 打印工具 |
| `performance-utils.js` | 性能优化 |
| `debug-logger.js` | 调试日志 |
| `permission.js` | 权限管理 |
| `vendor/xlsx.full.min.js` | Excel 导入库 |

**使用方式**：修改 `_shared/` 中的 JS 文件后，运行 `sync-all.bat` 自动同步到三个版本的根目录、electron/ 和 android/assets/public/。

### 1.3 通用技术栈

| 组件 | 技术 |
|---|---|
| 前端 | 纯 HTML + JavaScript（单文件 index.html） |
| 桌面端框架 | Electron + better-sqlite3 |
| 手机端框架 | Capacitor + @capacitor-community/sqlite |
| 数据库 | SQLite（本地）+ localStorage（缓存） |
| Excel 导入 | xlsx.full.min.js |
| 图表 | Chart.js（统计分析） |

### 1.4 文件结构

```
offline_project/
├── _shared/                     # 共享代码层（9个JS模块 + vendor）
├── sync-all.bat                 # 一键同步 _shared/ 到三个版本
├── db-bendi/                    # 本地版
│   ├── index.html               # 前端核心
│   ├── electron/                # Electron 主进程
│   ├── android/                 # Android 项目
│   ├── vendor/                  # xlsx 库
│   ├── config.json              # 版本配置
│   ├── packaging.bat/ps1        # 统一打包工具（中文菜单）
│   ├── build.bat                # 桌面端打包
│   ├── build-app.bat            # Android 打包
│   ├── sync-to-app.bat          # 同步到 Android assets
│   └── edit-config.ps1          # 配置修改脚本
├── db-dingzhi/                  # 定制版（结构同上）
└── db-geren/                    # 个人版（结构同上）
```

## 四、近期优化记录（2026-06-28 ~ 2026-07-06）

### 4.1 登录流程优化

- **登录界面适配**：移动端登录框宽度 92%，按钮高度 48px，字体 18px
- **自动聚焦**：用户名输入后按 Enter 自动聚焦密码框
- **记住密码**：localStorage 保存密码（已加密）

### 4.2 处方纸移动端优化

- 处方纸直接显示（无缩放），padding 缩小到 12px
- 字体缩小：诊所名称 14px，处方标题 16px，信息行 10px
- 药品表格行高 14px，字体 9px
- 患者信息单行紧凑布局，输入框最小宽度适配

### 4.3 统计分析增强

- 新增月度统计报表（定制版/个人版）
- 统计卡片四宫格：总就诊人数/初诊人数/复诊人数/复诊率
- 就诊次数筛选：1诊/2诊/3诊/4诊及以上
- 多种排序方式：就诊次数/最近就诊

### 4.4 安全优化

- 全局错误处理：`window.error` + `unhandledrejection`
- 自定义 prompt 弹窗替代原生 `prompt()`（定制版/个人版）
- SQL 注入防护：全部参数化查询
