============================================================
惠康中医系统 · 云端客服离线激活使用说明
============================================================

一、文件清单（根目录下 3 个文件）
------------------------------------------------------------
1. start-license.bat       ← 双击此文件运行（推荐）
2. generate-license.ps1    ← 实际执行脚本（修改客户信息）
3. 客服离线激活-使用说明.txt ← 本说明文件
------------------------------------------------------------
注：.bat 和 .ps1 用英文文件名是为了避免 cmd.exe 中文编码乱码
    导致双击闪退问题。文件内容仍是中文。

二、脚本使用步骤（客服操作）
------------------------------------------------------------
1. 用记事本打开 generate-license.ps1
   （右键文件 → 打开方式 → 记事本）

2. 修改【2】区段的 3 处客户信息：
     code       = "客户的激活码（格式 BNZC-XXXX-XXXX-XXXX-XXXX）"
     machineId  = "客户的 32 位机器ID（字母数字）"
     clinicName = "客户的诊所全称（与注册一致，含全角字符）"

3. 保存文件（Ctrl+S），关闭记事本

4. 双击 start-license.bat 启动

5. 看到 "✅ 离线激活文件已生成" 提示后
   桌面会自动生成 license.dat 文件

6. 把 license.dat 通过微信/QQ/邮件发给客户
   · 微信发送 .dat 可能被拦截，建议改后缀为 .txt 发送
   · 客户接收后改回 .dat

------------------------------------------------------------

三、发给客户操作步骤（客服直接转发）
------------------------------------------------------------
1. 接收客服发送的 license.dat 文件，保存到电脑桌面
2. 打开诊所管理软件 → 顶部【激活】窗口
3. 点击按钮「📁 导入离线激活文件」
4. 选中桌面 license.dat，点击确认完成激活
5. 查看软件右上角授权到期时间核对是否匹配
------------------------------------------------------------

四、常见报错排查（管理员/客服通用）
------------------------------------------------------------

【1】返回 401 鉴权失败
   原因：X-Export-Secret 密钥和 Cloudflare 后台 Secrets 不一致、密钥被重置
   处理：管理员登录 Cloudflare Pages 重新复制密钥替换脚本内字符串
         路径：dash.cloudflare.com → Workers & Pages → tcm-prescription-system
              → Settings → Variables and Secrets → LICENSE_EXPORT_SECRET

【2】返回 400 参数错误
   原因三选一：
     ① 机器 ID 少位 / 多空格（必须严格 32 位）
     ② 诊所名称文字、标点、空格和注册时不一致
     ③ 激活码输入错误
   处理：让客户重新复制激活页面原始信息，一字不差填入脚本

【3】执行脚本提示网络超时
   说明：客户机器断网不影响，客服电脑必须能联网调用 Cloudflare 云端接口
   处理：客服检查电脑网络、关闭代理/加速器重试

【4】客户导入 license.dat 提示授权无效
   处理：
     1. 核对脚本内填入的 3 项信息和客户软件显示完全一致
     2. 确认生成文件时未复制错其他客户信息
     3. 重新执行脚本生成新文件发送客户

【5】返回 "激活码已过期"
   处理：联系管理员在管理后台 /api/license/extend 延期激活码

【6】返回 "激活码已被禁用"
   处理：联系管理员在管理后台 /api/license/status 启用激活码

【7】返回 "此激活码已绑定诊所，必须提供 clinicName"
   处理：让客户提供激活窗口显示的诊所名称

【8】返回 "诊所名与激活码绑定的诊所不一致"
   处理：让客户从激活窗口复制完整诊所名，注意全角字符、标点

【9】客户导入时提示"激活文件与本机不匹配"
   处理：确认客户提供的机器ID与生成时使用的一致（每台机器ID不同）

【10】客户导入时提示"授权文件写入权限不足"
   处理：让客户右键"以管理员身份运行"软件
   （常见于安装在 Program Files 的客户）

【11】双击 .bat 闪退
   原因：可能是 Windows 执行策略限制
   处理：
     1. 用管理员身份打开 PowerShell
     2. 执行：Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
     3. 输入 Y 确认
     4. 再次双击 .bat

五、安全须知
------------------------------------------------------------
· 客服密钥（X-Export-Secret）严禁泄露，仅限客服本人使用
· 每个 license 仅对一台机器有效，machineId 不同无法激活
· 激活码调用后标记为已使用，无法二次激活（同机重激活除外）
· 同机重激活允许，适用于客户重装系统场景
· 换机激活：若设备配额已满，接口自动解绑最旧设备允许换机
· masterKey（在 license 中）绝对不能泄露，泄露后可伪造 license
------------------------------------------------------------

六、接口技术参数（管理员参考）
------------------------------------------------------------
接口地址：POST https://tcm-prescription-system.pages.dev/api/license/export-license
请求头：
  Content-Type: application/json
  X-Export-Secret: [客服密钥]
  （或 Authorization: Bearer [管理员token]）
请求体（JSON）：
  {
    "code": "BNZC-XXXX-XXXX-XXXX-XXXX",  // 必填
    "machineId": "32位机器ID",            // 必填，长度 8-128
    "clinicName": "诊所名",                // 条件必填（已绑定诊所时）
    "user": "用户名"                      // 可选，覆盖激活码上的 user
  }
返回体（成功）：
  {
    "success": true,
    "license": "base64编码字符串",
    "licenseInfo": { user, type, issuedAt, expiresAt, ... },
    "fileName": "建议文件名",
    "message": "提示信息"
  }
返回体（失败）：
  { "success": false, "error": "错误信息" }

七、密钥配置位置（管理员参考）
------------------------------------------------------------
Cloudflare Pages 后台：
  dash.cloudflare.com
  → Workers & Pages
  → tcm-prescription-system
  → Settings
  → Variables and Secrets
  → LICENSE_EXPORT_SECRET（Production 环境，Plain text 类型）

修改密钥后必须触发重新部署才生效：
  → Deployments → Retry deployment
  或推送任意 commit 到 GitHub main 分支
