## 二、归档操作指引

### 2.1 Git 提交历史存档（已完成）

- 文件：`evidence/git-commit-history.txt`（UTF-8，含证据说明头 + 全部 1879 次提交的完整哈希/作者/时间/标题，时间正序）
- 复核方法：任取一条 `commit XXXX` 哈希，到 GitHub 仓库 compare 页面核对一致性
- 增量更新：软件后续大版本（如 V2.0）另行登记前，重新导出一次并另存（勿覆盖 V1.0.0 存档）

### 2.2 云端部署记录导出（提交登记前完成）

```
npx wrangler pages deployment list --project-name=tcm-prescription-system > software_copyright\evidence\deployments.txt
```

部署时间线与"首次发表日期 2026-07-29"相互印证（若选"已发表"）。

### 2.3 开发决策与需求记录（提交登记前完成）

- 归档内容：本项目开发过程中的需求描述、功能方案确认、优化指令等对话/文档记录（按时间整理）
- 归档要求：注明日期；电子记录保留原始载体（勿仅存截图转录件）
- AI 辅助开发说明：本软件开发过程使用 AI 编程工具辅助实现，但软件的功能设计、技术方案、验收标准均由公司主导决策——归档需求与指令记录即可印证"公司主导开发"，不影响公司作为著作权人的登记

### 2.4 完成版安装包封存（提交登记前完成）

- 将 2026-07-29 前后构建的各端安装包（exe/apk）复制一份至 `evidence/` 或离线介质
- 命名：`惠康中医_完成版_20260729_<端>.exe/apk`；记录文件 SHA256 哈希（`Get-FileHash`）写入本清单附表
