




# 惠康中医诊所管理系统 操作说明书




版本：V1.0

编制日期：2026年07月

适用版本：离线版 / 云端版（安卓APP端 + 电脑桌面端）




---




## 第一章 系统概述




### 1.1 系统简介

惠康中医诊所管理系统是一款面向中医诊所日常经营管理的信息化工具，主要用于诊所的处方档案管理、药品库存台账维护、患者档案管理、经营数据统计分析以及多端数据同步备份等工作。系统以"录入便捷、存档规范、统计清晰、多端协同"为设计理念，帮助诊所实现纸质台账的电子化管理，提升日常办公效率。系统仅承担管理、记账、存档职能，不包含任何诊疗治病相关功能。




### 1.2 技术架构

系统采用 Capacitor 跨端框架 + HTML5 + JavaScript 前端技术栈开发，数据持久层使用 SQLite（移动端）与 IndexedDB（桌面端/Web端）相结合的本地存储方案，云端版额外接入 Cloudflare Workers 服务端 API 完成多端数据同步。整套架构具备以下特点：

- 前端界面采用响应式布局，自适应手机屏幕与电脑显示器
- 本地数据库采用嵌入式 SQLite/IndexedDB，无需独立部署数据库服务器
- 用户密码采用 SHA-256 算法加密存储，保障账户安全
- 备份文件使用 HMAC 签名校验，防止数据被篡改
- 云端同步采用增量推送/拉取机制，节省流量




### 1.3 运行环境要求

一、安卓端运行环境：

- 操作系统：Android 7.0（API 24）及以上版本
- 存储空间：剩余可用空间不少于 100MB
- 运行内存：建议 2GB 及以上
- 权限要求：存储读写权限、相机权限（用于处方照片采集）




二、桌面端运行环境：

- 操作系统：Windows 7/10/11（64位）
- 存储空间：剩余可用空间不少于 200MB
- 运行内存：建议 4GB 及以上
- 显示器分辨率：建议 1366×768 及以上




### 1.4 版本说明

- 离线版：所有数据保存在本地设备，无需联网即可使用，适合单机办公场景
- 云端版：在离线版基础上增加云端同步能力，支持多台设备共享同一份数据，适合多端协同办公场景
- 安卓APP端：通过 APK 安装包安装运行于安卓设备
- 电脑桌面端：通过 exe 安装程序安装运行于 Windows 系统，亦提供便携版（免安装直接运行）

## 第二章 安装与启动




### 2.1 安卓端安装

一、APK 安装步骤：

1. 将安装包文件 HuikangTCM.apk 拷贝至安卓设备的存储目录中
2. 在设备文件管理器中找到该 APK 文件并点击
3. 系统弹出"允许安装来自此来源的应用"提示时，前往设置开启对应权限后返回继续安装
4. 安装界面显示应用名称"惠康中医诊所管理系统"、版本号、所需权限列表，点击"安装"按钮
5. 安装进度条走完后点击"打开"或"完成"，桌面将生成应用图标




二、权限说明：

- 存储权限：用于读取与写入备份文件、导出处方数据、保存处方图片归档
- 相机权限：用于在处方录入过程中拍摄处方笺照片并归档存档（仅在用户主动触发拍照时调用）
- 应用首次启动时，系统将依次弹窗请求上述权限，用户可选择"允许"或"仅使用时允许"




### 2.2 桌面端安装

一、安装版安装步骤：

1. 双击运行安装程序 HuikangTCM_Setup.exe
2. 安装向导启动后，点击"下一步"进入许可证协议页面，阅读后勾选"我接受协议"
3. 选择目标安装位置（默认 C:\Program Files\HuikangTCM\），点击"下一步"
4. 选择开始菜单文件夹，可选择是否创建桌面快捷方式
5. 点击"安装"开始复制文件，完成后勾选"运行惠康中医诊所管理系统"并点击"完成"




二、便携版与安装版的区别：

- 安装版：将程序文件写入系统目录，自动注册开始菜单与桌面快捷方式，支持开机自启动配置，卸载时通过控制面板完成
- 便携版：为单一 exe 文件，无需安装直接双击运行，配置文件与数据保存在 exe 同级目录下，便于 U 盘携带与多机使用，但不支持开机自启动




### 2.3 首次启动配置

首次启动系统时，将自动初始化本地数据库并创建默认管理员账户。默认管理员账户信息如下：

- 用户名：admin
- 初始密码：admin123

为保证账户安全，首次登录后请及时前往"账户管理"修改默认密码。




### 2.4 登录界面说明

启动应用后进入登录界面，界面布局如下：

- 顶部：显示应用图标与"惠康中医诊所管理系统"标题文字
- 中部：用户名输入框（带占位提示"请输入用户名"）、密码输入框（密码以圆点掩码显示，右侧带眼睛图标可切换明文/密文）
- 下部：左侧"记住用户名"复选框、右侧并排的"登录"按钮与"取消"按钮

操作说明：

- 在用户名输入框输入账号，密码输入框输入密码
- 勾选"记住用户名"后，下次启动时用户名输入框将自动填充上次使用的账号
- 点击"登录"按钮提交验证，验证通过进入主界面，验证失败弹出提示"用户名或密码错误"
- 点击"取消"按钮将退出当前程序

## 第三章 用户登录与权限管理




### 3.1 登录流程

一、登录操作步骤：

1. 启动应用进入登录界面
2. 在用户名输入框中输入账号（亦可点击输入框右侧下拉箭头从历史记录中选择）
3. 在密码输入框中输入登录密码
4. 点击"登录"按钮进行身份验证
5. 系统校验账号是否存在、密码是否匹配（SHA-256 比对），通过后加载该用户对应权限并进入主界面
6. 若连续输错密码超过 5 次，账户将被临时锁定 10 分钟，期间无法登录




### 3.2 用户管理

用户管理功能仅管理员可见，入口位于主界面右上角"账户管理"按钮（齿轮图标）。进入后界面布局如下：

- 顶部工具栏：左侧"新增用户"按钮、右侧搜索框（可按用户名检索）
- 中部表格：列依次为"用户名""姓名""角色""创建时间""操作"
- 操作列含"编辑""删除"两个文字按钮




一、新增用户：

1. 点击"新增用户"按钮，弹出用户新增对话框
2. 依次填写用户名（必填，不可与已有用户重复）、姓名（必填）、初始密码（必填，不少于 6 位）、确认密码、角色（下拉选择"管理员"或"普通用户"）
3. 点击"保存"完成新增，点击"取消"放弃本次操作




二、编辑用户：

1. 在用户列表中找到目标用户，点击该行"编辑"按钮
2. 弹出编辑对话框，可修改姓名、密码、角色信息（用户名不可修改）
3. 修改完成后点击"保存"




三、删除用户：

1. 点击目标用户行的"删除"按钮
2. 系统弹出二次确认框"确定删除该用户？"
3. 点击"确定"完成删除，点击"取消"放弃

注：当前登录的管理员账户不可删除自身；系统至少需保留一个管理员账户。




### 3.3 密码安全

一、密码加密存储：

- 系统所有用户密码均采用 SHA-256 哈希算法加密后存入数据库，数据库中不存在明文密码
- 即使数据库文件被非法获取，也无法直接还原出原始密码




二、密码修改：

1. 登录后点击主界面右上角用户头像，选择"修改密码"
2. 弹出修改密码对话框，依次填写原密码、新密码、确认新密码
3. 新密码需不少于 6 位，建议字母与数字组合
4. 点击"确定"提交，原密码校验通过后即修改成功




### 3.4 权限控制

系统设置两类角色：

- 管理员：可见"账户管理"入口，可新增/编辑/删除用户、分配角色，可使用全部功能模块（含基础设置、数据备份与恢复、清空数据）
- 普通用户：不可见"账户管理"入口，仅可操作处方录入、处方历史、病例管理、药品管理、验方管理等日常业务功能，不能进行数据清空与系统级配置操作

## 第四章 基础设置




基础设置入口位于主界面左侧导航栏"系统设置"菜单项，仅管理员可见可编辑。界面采用表单布局，各设置项纵向排列，底部统一"保存设置"按钮。




### 4.1 诊所名称设置

- 输入框标签："诊所名称"
- 用于在处方笺顶部、统计报表表头处显示
- 保存后即时生效，新打印的处方笺将采用最新名称




### 4.2 医师姓名配置

- 输入框标签："医师姓名"
- 用于处方笺落款医师签名处显示
- 支持保存多个医师姓名，在处方录入界面可通过下拉框选择本次开方医师




### 4.3 诊疗费设置

- 输入框标签："诊疗费（元）"
- 数字输入框，仅允许输入数字与小数点
- 该费用将作为默认值自动加入处方金额合计中，可在处方录入时手动调整




### 4.4 默认剂数设置

- 输入框标签："默认剂数"
- 数字输入框，整数
- 新建处方时"剂数"字段将自动填入该默认值（如 7），减少重复输入




### 4.5 开机自启动设置（桌面版）

- 复选框标签："开机自启动"
- 勾选后，系统将在 Windows 启动时自动运行并停留在登录界面
- 仅安装版支持此功能，便携版该选项置灰不可用
- 修改后点击底部"保存设置"按钮生效




所有设置项修改完成后，点击页面底部"保存设置"按钮，系统提示"设置已保存"即完成配置。

## 第五章 药品管理




药品管理模块用于维护诊所中药字典与库存台账，入口位于主界面左侧导航栏"药品管理"菜单。




### 5.1 药品列表查看与搜索

进入药品管理界面后，布局如下：

- 顶部工具栏：左侧搜索框（占位提示"输入药品名称或简码搜索"）、"新增药品"按钮、"导入"按钮、"导出"按钮、"清空药物库"按钮
- 中部表格：列依次为"序号""药品名称""简码""进价""单价""单位""常用用量""库存数量""操作"
- 操作列含"编辑""删除"两个文字按钮
- 底部：分页控件与"共 X 条"统计文字




搜索操作：在搜索框中输入药品名称全称或简码（如"黄芪"或"HQ"），表格实时过滤显示匹配结果；清空搜索框内容即恢复显示全部药品。




### 5.2 新增药品

1. 点击顶部"新增药品"按钮，弹出新增加药对话框
2. 对话框字段如下：
   - 药品名称（必填）：如"黄芪"
   - 简码（必填）：药品名称拼音首字母缩写，如"HQ"，用于处方录入时快速检索
   - 进价（必填）：数字，单位元，用于成本核算
   - 单价（必填）：数字，单位元，用于处方金额计算
   - 单位（必填）：下拉选择"克""付""包""瓶"等
   - 常用用量（必填）：数字，默认单剂用量，如 10
   - 库存数量（必填）：数字，当前库存余量
3. 填写完成后点击"保存"，新药品即出现在列表末尾；点击"取消"放弃新增




### 5.3 编辑药品

1. 在药品列表中找到目标药品，点击该行"编辑"按钮
2. 弹出编辑对话框，字段与新增一致，已自动填入原有数据
3. 修改所需字段后点击"保存"，列表即时刷新




### 5.4 删除药品

1. 点击目标药品行的"删除"按钮
2. 系统弹出二次确认框"确定删除药品【XXX】？"
3. 点击"确定"完成删除

注：已被历史处方引用的药品删除后，历史处方数据不受影响，仍保留原药品名称记录。




### 5.5 药品导入导出

一、导出药品：

1. 点击顶部"导出"按钮，弹出格式选择菜单，提供"CSV""JSON""Excel"三种格式选项
2. 选择所需格式后，系统将当前药品列表全部数据导出为文件
3. 桌面端将弹出文件保存对话框选择保存路径；安卓端文件默认保存至 downloads 目录




二、导入药品：

1. 点击顶部"导入"按钮，弹出文件选择对话框
2. 选择本地 CSV/JSON/Excel 药品文件
3. 系统解析文件并预览前 5 条数据，确认无误后点击"开始导入"
4. 导入策略：药品名称已存在则更新其字段，不存在则新增




### 5.6 清空药物库

1. 点击顶部"清空药物库"按钮（红色文字标识）
2. 系统弹出二次确认框"此操作将清空全部药品数据且不可恢复，确定继续？"
3. 需在确认框中手动输入"确认清空"文字后，"确定"按钮才可点击
4. 点击"确定"完成清空

注：该操作仅管理员可执行，清空前建议先导出备份。

## 第六章 验方管理




验方管理模块用于维护诊所常用经验方剂字典，便于处方录入时快速调用，入口位于主界面左侧导航栏"验方管理"菜单。




### 6.1 验方列表查看与搜索

界面布局与药品管理类似：

- 顶部工具栏：搜索框（占位提示"输入验方名称或简码搜索"）、"新增验方"按钮
- 中部表格：列依次为"序号""验方名称""简码""功效""主治""药物组成""操作"
- "药物组成"列以文字简述所含药物及用量，如"黄芪30g 当归10g ……"




搜索操作：在搜索框输入验方名称或简码，表格实时过滤。




### 6.2 新增验方

1. 点击"新增验方"按钮，弹出新增对话框
2. 对话框字段：
   - 名称（必填）：如"补中益气汤"
   - 简码（必填）：拼音首字母缩写，如"BZYQT"
   - 功效（选填）：文字描述验方功效类别
   - 主治（选填）：文字描述适用范围
   - 药物组成（必填）：点击"添加药物"按钮在下方逐条添加药品，每条可选择药品（下拉搜索）、填写用量（数字+单位）
3. 完成后点击"保存"




### 6.3 编辑验方

点击验方行的"编辑"按钮，弹出编辑对话框，可修改全部字段，亦可增删药物组成条目，修改后点击"保存"。




### 6.4 删除验方

点击验方行的"删除"按钮，二次确认后完成删除。删除验方不影响历史处方数据。




### 6.5 验方选用

在处方录入界面，提供"调用验方"按钮，点击后弹出验方选择列表，支持搜索。选中某验方后，该验方包含的全部药物及用量将一键导入到处方药品列表中，用户可在导入基础上进一步调整。此功能用于提升常规处方的录入效率。

## 第七章 处方录入




处方录入是系统的核心功能模块，入口位于主界面左侧导航栏"处方录入"菜单，或主界面中央醒目的"新建处方"快捷按钮。




### 7.1 患者信息录入

处方录入界面顶部为患者信息区，采用左右两列表单布局：

- 姓名（必填）：文本输入框
- 性别（必填）：单选下拉框"男/女"
- 年龄（必填）：数字输入框，单位"岁"
- 电话（选填）：文本输入框，支持 11 位手机号
- 住址（选填）：文本输入框

若患者已存在历史档案，在姓名输入框输入时系统将自动联想匹配历史患者，选中后自动填充性别、年龄、电话、住址等信息。




### 7.2 处方编号自动生成规则

处方编号由系统自动生成，规则为"YYMMDD+两位序号"，例如 2026 年 7 月 15 日第 3 张处方编号为"26071503"。序号按当日累计递增，每日零点重置。编号在处方保存时生成，保存前显示为"待生成"。




### 7.3 病史症状记录

患者信息区下方为"病史症状"多行文本框，可输入主诉、现病史、既往史等文字记录，作为档案留存用途。




### 7.4 诊断信息录入

病史症状下方为"诊断"文本输入框，可输入诊断名称作为档案归类依据。




### 7.5 药品选择

诊断信息下方为处方药品列表区，布局如下：

- 顶部一行：药品简码/名称快速输入框、"调用验方"按钮、"添加药品"按钮
- 中部表格：列依次为"序号""药品名称""用量""单位""单价""小计""操作"（操作列含"删除"按钮）
- 底部一行：显示药品条数统计




药品选择两种方式：

一、简码输入自动匹配：

1. 在快速输入框中输入药品简码（如"HQ"）或名称部分字符
2. 输入框下方实时弹出匹配药品列表（最多显示 10 条）
3. 通过键盘上下方向键或鼠标选中目标药品，按回车键确认
4. 该药品即添加至药品列表中，默认用量取自药品字典"常用用量"




二、手动输入药名：

1. 点击"添加药品"按钮，药品列表新增一空白行
2. 在药品名称单元格中手动输入药名（若与字典药品匹配，单价将自动带入）
3. 依次填写用量、单位、单价




每条药品的"小计"列由系统按"用量×单价"自动计算。点击"删除"按钮可移除该条药品。




### 7.6 剂数设置与金额计算

药品列表下方为金额计算区，布局如下：

- 剂数输入框：数字输入框，默认取自基础设置的"默认剂数"
- 每剂单价：只读显示，为药品列表所有小计之和
- 药费总计：只读显示，等于"每剂单价×剂数"
- 诊疗费：数字输入框，默认取自基础设置，可手动修改
- 总计金额：只读显示，等于"药费总计+诊疗费"

任一相关字段变化时，金额自动重新计算。




### 7.7 处方笺实时预览

界面右侧为处方笺实时预览区，随左侧录入内容实时刷新。预览区采用 A5 纵向版式，自上而下依次显示：

1. 诊所名称（粗体居中，取自基础设置）
2. "处方笺"标题
3. 处方编号、开方日期
4. 患者姓名、性别、年龄
5. 病史症状、诊断
6. 药品组成表格（药名、用量、单位）
7. 剂数、药费、诊疗费、总计金额
8. 医师签名、调剂、核对等落款栏

预览区内容与最终打印效果一致。




### 7.8 处方保存

确认录入无误后，点击界面底部"保存处方"按钮，系统执行以下动作：

1. 生成处方编号
2. 将处方数据写入本地数据库
3. 若为云端版且当前在线，同时推送到云端待同步队列
4. 弹出"处方保存成功，编号：XXXXXX"提示

保存后处方进入历史档案，可随时调阅。点击"清空"按钮可重置当前录入界面，开始下一条处方录入。




### 7.9 处方打印

点击界面底部"打印"按钮，弹出打印设置对话框：

- 纸张：固定 A5
- 方向：单选"纵向"/"横向"
- 打印机：下拉选择已连接打印机
- 预览区：右侧显示打印效果

点击"打印"按钮调起系统打印对话框完成输出；点击"取消"关闭窗口。打印内容与预览区一致，便于诊所存档或交付患者。

## 第十一章 数据备份与恢复




数据备份与恢复模块用于保障诊所数据安全，入口位于主界面左侧导航栏"数据备份"菜单，仅管理员可操作。




### 11.1 一键备份

界面顶部为"一键备份"按钮，点击后系统执行以下动作：

1. 收集本地数据库中的药品字典、验方字典、处方档案、患者档案、用户账户、基础设置等全部数据
2. 序列化为 JSON 格式
3. 使用 HMAC 算法对备份数据生成签名，签名附加在文件尾部
4. 生成备份文件，文件名格式为"huikang_backup_YYYYMMDD_HHmmss.json"
5. 桌面端弹出保存对话框选择路径；安卓端自动保存至 downloads/YYYY-MM/ 目录下
6. 完成后提示"备份成功，文件已保存至 XXX"




### 11.2 备份文件 HMAC 签名验证

为保证备份文件完整性、防止数据被篡改，系统在恢复数据时会执行 HMAC 签名校验：

- 读取备份文件中的数据部分与签名部分
- 使用内置密钥对数据部分重新计算 HMAC 值
- 比对计算结果与文件中的签名，一致方可恢复，不一致则拒绝并提示"备份文件已损坏或被篡改"




### 11.3 恢复数据

1. 点击界面"恢复数据"按钮，弹出文件选择对话框
2. 选择本地备份 JSON 文件
3. 系统解析并校验签名，校验通过后显示备份文件摘要信息（备份时间、药品数、处方数等）
4. 点击"开始恢复"，系统清空当前本地数据并写入备份数据
5. 恢复完成后提示"数据恢复成功，建议重启应用"




### 11.4 备份文件保存路径说明

- 安卓端：自动保存至设备存储的 downloads/YYYY-MM/ 目录，例如 downloads/2026-07/huikang_backup_20260715_103020.json
- 桌面端：由用户在保存对话框中自定义路径
- 建议定期将备份文件复制至其他存储介质或网盘，实现异地容灾




### 11.5 清空数据功能

界面底部为"清空全部数据"按钮（红色文字标识）：

1. 点击按钮，弹出二次确认框
2. 需在确认框中手动输入"确认清空"文字后方可点击"确定"
3. 系统清空本地数据库全部数据（药品、验方、处方、病例、用户、设置），仅保留默认管理员账户

注：该操作不可恢复，执行前务必先完成一键备份。仅管理员可执行。

## 第十二章 离线同步与多端切换




离线同步与多端切换是云端版的核心能力，入口位于主界面左侧导航栏"同步管理"菜单，仅云端版可见。




### 12.1 离线数据库说明

系统采用本地优先（Local-First）的存储策略：

- 安卓端：使用嵌入式 SQLite 数据库，所有日常操作产生的数据先写入本地
- 桌面端/Web端：使用浏览器 IndexedDB 存储
- 即使设备处于断网状态，所有录入、查询、统计功能均可正常使用，不受网络影响




### 12.2 云端同步机制

云端同步采用"增量推送 + 增量拉取"双向机制：

一、未同步数据推送：

- 系统在后台自动检测本地新增/修改的数据，并标记为"待推送"
- 当设备联网且用户处于同步管理界面或触发手动同步时，将待推送数据打包发送至云端服务端 API
- 推送成功后，本地对应数据标记为"已同步"




二、云端数据拉取：

- 系统记录上次拉取时间戳，向云端请求该时间点之后变更的数据
- 拉取到的数据合并写入本地数据库，并更新本地时间戳
- 合并策略：以最新修改时间为准，相同记录后修改的覆盖先修改的




### 12.3 同步状态查看

同步管理界面顶部为状态卡片区，显示以下信息：

- 上次推送时间：YYYY-MM-DD HH:mm:ss，未推送则显示"从未"
- 上次拉取时间：YYYY-MM-DD HH:mm:ss，未拉取则显示"从未"
- 待同步条数：当前本地待推送数据条数
- 同步状态：显示"已同步"/"待同步"/"同步中"/"同步失败"




状态卡片下方提供"立即同步"按钮，点击后依次执行推送与拉取流程，并在界面下方滚动显示同步日志（每条数据的时间、类型、结果）。




### 12.4 多端数据一致性保障

- 每条数据记录均包含全局唯一 ID、创建时间、最后修改时间、版本号字段
- 多端修改冲突时以"最后修改时间"为准进行合并
- 删除操作采用软删除标记，同步时传播删除意图，避免数据残留
- 建议多端协同办公时，每次开始工作前先执行一次"立即同步"拉取最新数据，结束工作前再执行一次同步推送本地变更




### 12.5 本地离线模式与云端模式切换

系统支持在"本地离线模式"与"云端模式"之间切换：

- 本地离线模式：仅使用本地数据库，不与云端通信，适合单机使用或网络不稳定场景
- 云端模式：启用后台自动同步，适合多端协同场景

切换入口位于同步管理界面顶部的模式切换开关。切换至云端模式时，系统将提示用户登录云端账户并完成首次全量同步；切换至本地离线模式时，已同步至本地的数据仍可正常使用，仅停止后续自动同步。
