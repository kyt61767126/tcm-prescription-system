惠康中医诊所管理系统 - 软件简要说明

一、软件名称
惠康中医诊所管理系统（简称：惠康中医管理系统）

二、软件版本
V1.0.0

三、软件开发目的
本软件面向中医诊所的日常管理需求，提供处方电子化录入、药品库存管理、患者档案存档、经营数据统计等功能，替代传统纸质处方和手工记账方式，提升诊所信息管理效率。系统仅承担管理、记账、存档职能，不涉及诊疗治病功能。

四、技术架构
采用 Capacitor + HTML + JavaScript + SQLite 技术栈开发，前后端一体化架构。前端基于 HTML5 + JavaScript 渲染界面，数据层使用 IndexedDB（浏览器端）和 better-sqlite3（桌面端）双引擎存储，支持离线使用。通过 Electron 框架打包为 Windows 桌面应用程序，通过 Capacitor 框架打包为 Android APP，实现一套代码多端运行。

五、主要功能
1. 处方管理：处方电子化录入，自动生成处方编号（YYMMDD+序号），支持药品简码快速检索、金额自动计算、A5纸张打印。
2. 药品管理：中药字典维护，记录药品名称、简码、进价、单价、库存等信息，支持批量导入导出。
3. 验方管理：常用验方模板存储，可一键导入处方，提高录入效率。
4. 患者档案：患者基本信息存档，就诊历史记录查询，支持按姓名、日期检索。
5. 统计分析：就诊人次统计、收入成本核算、月度报表生成、趋势图表展示。
6. 数据备份：一键导出 JSON 备份文件，含 HMAC 签名防篡改验证，支持数据恢复。
7. 多端同步：离线数据本地存储，云端同步引擎支持多设备数据一致性。
8. 用户权限：多用户管理，管理员/普通用户角色分配，密码 SHA-256 加密存储。

六、运行环境
- 安卓端：Android 7.0 及以上版本
- 桌面端：Windows 10 及以上版本
- 内存要求：2GB 及以上
- 存储空间：200MB 及以上

七、软件特点
1. 离线可用：无需网络即可完成所有操作，数据本地存储。
2. 多端覆盖：安卓 APP + 电脑桌面端，数据互通。
3. 安全可靠：密码加密存储，备份数据 HMAC 签名验证，CSP 安全策略防护。
4. 操作简便：简码输入、自动计算、一键打印，贴合诊所实际工作流程。
