# 优化打包：一键打包 + 手动打包（离线/云端同步优化）

> 本次任务（2026-08-18）目标：提高打包速度、统一一键/手动打包行为、离线/云端手动脚本对齐、清理旧打包产物释放空间。验证方式：仅验证手动打包。

## 一、当前打包体系（8包→4包合并后的真实结构）

```
一键打包.bat ──▶ tools/one-click-pack.ps1 （图形菜单，2版本统一入口）
                      ├── app_project/db-yunduan\pack-desktop.bat ──▶ build-pack.bat desktop ──▶ cloud_desktop\build.bat
                      └── app_project/db-yunduan\build-pack.bat app-strict ──▶ build-app.bat standard（严格模式）
                      ├── app_project/db-offline\pack-desktop.bat ──▶ build-pack.bat desktop ──▶ desktop\build.bat
                      └── app_project/db-offline\build-pack.bat app-strict ──▶ app\build-app.bat standard（严格模式）

手动打包（用户双击对应目录下入口）：
  云端版:  db-yunduan\pack-desktop.bat / pack-app.bat / pack-app-strict.bat
  离线版:  db-offline\pack-desktop.bat / pack-app.bat / pack-app-strict.bat
```

- 一键打包与手动打包已统一：`one-click-pack.ps1` 调用的就是 `pack-desktop.bat` 与 `build-pack.bat app-strict`，与手动入口完全一致。
- APP 严格模式（app-strict）为默认安全档：签名哈希刷新 + Java 层混淆 + APK 签名哈希硬校验。

## 二、脚本对齐结论（本次核查）

| 脚本 | 离线 (db-offline) | 云端 (db-yunduan) | 对齐情况 |
|------|-------------------|-------------------|----------|
| build-pack.bat | desktop/app/app-strict | desktop/app/app-strict | ✅ 结构一致（仅产物名/路径不同） |
| pack-desktop/pack-app/pack-app-strict.bat | 委托 build-pack.bat | 委托 build-pack.bat | ✅ 一致 |
| desktop/build.bat | 清理dist+保留最近2个dist_old+obfuscate+pre-build-check+pre-flight+磁盘检查 | 同上（另清 build_output_old） | ✅ 已对齐 |
| app/build-app.bat | 版本一致性预检+诊所名硬编码扫描+签名哈希+gradlew clean+obfuscate+Java预编译 | 同左（cloud_app 目录） | ✅ 已对齐 |

> 说明：桌面 build.bat 的构建策略不同（离线=`npm run build`，云端=`prepare-win-unpacked.js`+electron-builder --prepackaged）属平台差异，不影响对齐语义；APP 脚本结构差异源于离线需从 desktop/ 同步资源到 Android assets，云端走 cloud_app，均为必要差异。

## 三、清理旧打包产物（本次实际执行，释放约 930MB）

已删除（均为可重建产物/旧命名残留，gitignore 已覆盖不入库）：

| 删除项 | 大小 |
|--------|------|
| app_project/db-offline/desktop/dist（重建产物） | 436.6 MB |
| app_project/db-yunduan/cloud_desktop/dist（重建产物） | 454.2 MB |
| output/（旧8包命名 LB/LJ/YB/YJ.apk，已由统一包取代） | 26 MB |
| db-offline/app/惠康中医-定制-Capacitor.apk、惠康中医-本地-Capacitor.apk（旧命名） | 8.3 MB |
| db-offline/LB.apk、LJ.apk（旧合并包命名） | 4.3 MB |
| db-offline/desktop/tmp_disk_d_only、dist_old_20260817_222837（残留） | ~0.3 MB |

**保留项（加速打包，勿删）**：
- `db-offline/desktop/node_modules`（488MB）、`db-yunduan/cloud_desktop/node_modules`（499MB）— 依赖复用避免重装
- `tools/.eb-cache`（97MB）、`tools/.npm-cache`（64MB）— electron-builder/npm 跨版本共享缓存（pack.ps1 引用）

> 桌面 build.bat 每次打包前自动清理 dist 并保留最近 2 个 dist_old；APP build-app.bat 每次 gradlew clean。因此手动打包无需额外手动清理，旧产物只在"打包完成后不再打包"的场景下才需要手动清理本清单。
