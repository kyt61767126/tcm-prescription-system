# 「智能语音输入版」第一期实施计划

> 依据：用户上传的《智能语音输入版独立版本实施方案 V1.0》（四期 8-10 周之首期，2 周）
> 范围：voice 版本类型体系 + 云端网页局部语音（四框麦克风）+ admin 后台枚举扩展
> 原则：与现有 trial/personal/pro 完全平行；单包+激活码解锁（方案A feature gate）；键盘开方零影响

## 一、Context（为什么做）

惠康中医诊所管理系统拟推出「智能语音输入版」独立版本线：语音版=标准版全部权益+语音输入，1年/1设备，建议定价 399–449 元。解锁方式=激活码类型 `voice`，服务端下发 `features:["voice"]`，客户端据此渲染语音入口；trial/personal/pro 激活后**无任何语音入口**（现有版本零感知）。

第一期只做云端网页（浏览器端 Web Speech API），云桌面/APP 的语音能力在三/四期（Electron/WebView 无 Web Speech API，本期内自动降级隐藏）。

## 三、实施步骤

### Step 1 服务端 voice 枚举（license 体系）
1. `license-core.js` `LICENSE_TYPE_CONFIG` 加：
   ```js
   voice: { maxPrescriptions: 0, features: ['backup', 'voice'] }  // 标准版权益+语音
   ```
2. `versionOf()`：voice → `'voice'`（新枚举值，不并入 standard）。
3. `entitlement.js`/`heartbeat.js`/`validate.js`：确认响应透传 features（buildLicenseData 已产 features，补聚合视图字段）；语音入口判定只信服务端下发。
4. `users.js` `normalizeClinicEdition` 加 `cloud_voice` 规范 key（精确命中 + 中文「语音版」别名）；`sanitizeUser` 透传（clinicEdition 已是透传通道，零结构改动）。

### Step 2 客户端枚举与归一化
1. `shared/license/license-manager.js` `LICENSE_TYPE_CONFIG` 加 voice（同 Step 1.1），跑 `sync-all.ps1` 分发 7 副本。
2. `shared/edition-lock.js` `__normalizeEdition` 显式登记 `cloud_voice`（原样返回，防止未来兜底逻辑误归一化）。
3. `shared/auth-core/cloud.js` 登录钩子（L1092-1127）：`clinicEdition==='cloud_voice'` → `targetEd='cloud_voice'` 写三处；跑 `tools/sync-auth-core.ps1`（8 副本）。
4. `shared/permission.js`：新增 `isVoiceEdition()` 辅助（edition==='cloud_voice'），供语音模块 gate 读取。

### Step 3 admin 后台 voice 枚举（双副本字节镜像）
1. 4 处下拉框各加 `<option value="voice">语音版（无限处方+语音输入，1年）</option>`。
2. typeLabel/typeNames/typeMap 加 `voice: '语音版'`；版本徽章用紫色系（与现有版本显示样式统一，参照 tag-personal/tag-pro 样式新增 tag-voice）。
3. 批量快捷模板加「语音 · 1年」按钮（`applyBatchTemplate('voice1y')`）。
4. 服务端签发默认值兜底（铁律 §7：发码默认策略放服务端按 type）：`admin-approve.js`/`activate-from-ticket.js` maxDevices 兜底 voice=1。
5. 字节镜像同步 `site-admin/admin/index.html`；`node tools/diff-cross-version.cjs`（adminconsole 对）绿灯。

### Step 4 语音模块骨架 `shared/voice/voice-input.js`（新文件）
```
VoiceInput IIFE：
- ASRProvider：Web Speech API（webkitSpeechRecognition，lang='zh-CN'，interimResults=false）
- isAvailable()：三重条件——① window.SpeechRecognition/webkitSpeechRecognition 存在
  ② 安全上下文（window.isSecureContext）③ feature gate（Permission.isVoiceEdition()）
  任一不满足 → 按钮不渲染（降级安全，键盘开方零影响）
- listen(targetField)：识别 → 回调填充；错误处理（not-allowed/no-speech/network）toast 提示
- 填充后浅紫色高亮待确认（P0 铁律：所有语音填充内容高亮待医生确认）
```
- 过 `node tools/smoke-runtime.cjs --all`（无 DOM 沙箱加载，window.* API 全 try-catch，S7 红线）。
- 分发：`sync-all.ps1` 登记新 target 组 + `copy-consistency.cjs` 加组（新增 shared 模块三处登记铁律：sync-all 组 + copy-consistency GROUPS + 确认打包 build.files 覆盖）。

### Step 5 四框麦克风按钮（public/index.html，JS 动态注入不改 HTML）
1. 新增注入 IIFE（DOMContentLoaded + 1.5s 双触发兜底）：
   - 姓名/年龄/诊断框旁、病史 textarea 旁插入 🎤 小按钮（22px 圆形，absolute 定位到输入框右侧，不破坏现有布局）；
   - 药物表格容器头部插入一个 🎤 语音加药按钮。
2. 填充行为：
   - 姓名/年龄/诊断/病史：识别文本填入对应框 + 高亮待确认；
   - 性别：识别文本含「男/女」关键词 → select 切换；
   - 药物：识别文本（药名或简码）→ 找到首个空行 `code-input-{i}`/`name-input-{i}` → 调 `showSearchDropdown(input, text, column)` 弹候选 → 医生点选 `selectMedicine`（**P0：无匹配绝不静默填充**）。
3. 公共函数走共面函数同步链：改 `public/index.html` 后必跑 `sync-html.ps1`（云桌面+云APP assets 自动传播，Electron/WebView 无 Web Speech 自动降级）+ `sync-siteadmin.cjs`（共面函数标记块）+ `diff-cross-version.cjs` 三对基线。

### Step 6 收尾（门禁 + 官网 + 提交）
1. `check-interface.bat` 前后各一次（基线 6/6 不变）。
2. 官网说明同步（流程铁律）：`public/download.html` ↔ `site-official/download.html` 双副本版本对比表加「语音版」行（权益/定价/适用场景），Playwright 双档验证，`diff-cross-version.cjs --pair download` 绿灯。
3. 全量门禁：`sync-all.ps1` 全绿 / `copy-consistency` 全绿 / 十道 pre-push。
4. commit + push（message 含生效方式段落）+ KNOWLEDGE.md 沉淀（新章节：语音版版本线）。

## 四、验证清单（新设备，用户偏好）

1. **voice gate**：voice 测试码激活/voice 测试诊所登录 → 云端网页四框出现 🎤；personal/pro/trial 登录 → 无任何语音入口（各用新设备逐一验证）。
2. **识别填充**：浏览器授权麦克风 → 说「张三」→ 姓名框填充+紫色高亮；性别/年龄/诊断/病史同理。
3. **语音加药**：说「黄芪」或简码 → 候选弹窗 → 点选 → 表格填充（含价格/剂量自动带入）。
4. **P0 铁律**：说一个不存在的药名 → 只弹「无匹配」提示，不填入任何内容。
5. **降级安全**：拒绝麦克风权限/非 https 环境 → 🎤 按钮隐藏，键盘开方全流程不受影响。
6. **admin**：签发 voice 码（4 处下拉框）→ 用户管理列表紫色「语音版」徽章 → 设备绑定 1 台。
7. **回归**：personal/pro 正常开方/备份/同步零变化（现有版本零感知）。

## 六、风险与预案

1. **Web Speech API 国内可用性**：Chrome 语音识别服务需联网，国内网络不稳——一期实测验证（用户偏好分阶段：先验证语音模块稳定性）；不可用则二期评估国内 ASR 备选，四期本地模型兜底。
2. **HTTPS 硬要求**：pages.dev 全站 https，满足麦克风安全上下文。
3. **共面函数同步义务**：public/index.html 改动触发 4 条同步链（sync-html/sync-siteadmin/diff-cross-version/check-interface），漏一即 push 门红灯。
4. **license-manager 7 副本**：只改 shared 权威源 + sync-all 分发，禁手改副本（铁律）。
