安装说明
Android APP 安装步骤
  1. 下载对应版本的 APK 文件到手机
  2. 在手机设置中允许"安装未知来源应用"（设置 → 安全 → 未知来源）
  3. 点击下载的 APK 文件进行安装
  4. 安装完成后打开 APP，首次使用需输入授权激活码
  5. 如遇"安装包损坏"提示，请重新下载并核对 SHA-256 校验值
Windows 桌面版安装步骤
  1. 下载安装版 exe 文件（推荐）或便携版
  2. 双击运行安装程序，按提示完成安装
  3. 安装完成后从桌面快捷方式启动
  4. 便携版无需安装，解压后直接运行 exe 即可
  5. 首次使用需输入授权激活码
如何校验文件完整性（SHA-256）
Windows certutil -hashfile 文件名 SHA256
Mac/Linux shasum -a 256 文件名

将计算结果与上方页面的 SHA-256 值比对，完全一致则文件完整无损。
