📝安装后首次使用指引
离线版（定制版 / 个人版）
  1. 使用默认账号登录后，立即进入"基础设置"
  2. 修改诊所名称、医师姓名（定制版支持多医师，个人版仅一个管理员）
  3. 修改默认密码为自定义密码，确保账户安全
  4. 根据需要配置药材库、处方模板、图片保存位置等
  5. 开始录入处方：选择患者 → 添加药材 → 调整剂量 → 保存处方
  6. 定期使用"设置 → 数据备份"导出数据到安全位置
☁️ 云端版
  1. 使用开发者提供的账户信息登录
  2. 多设备登入同一账户，数据自动云端同步
  3. 管理员可在云端管理后台管理用户、查看统计数据
  4. 云端数据自动备份，无需手动备份
📷 录像拍照功能（APP）
  1. 安装时请允许相机、麦克风、存储权限
  2. 在处方录入页面点击 🎥 录像按钮或 📷 拍照按钮
  3. 媒体文件自动按"处方编号_患者姓名"命名，保存在手机本地存储
  4. 支持先拍照录像后录入处方，系统自动绑定到最近保存的患者
🔒 试用期与激活
  1. 离线版提供 7 天免费试用（限 30 张处方），无需注册即可使用
  2. 试用满意后，请切换到"购买激活码"Tab 获取永久授权
  3. 激活码与设备绑定，一台设备对应一个激活码
🔑激活流程（试用到期后）
  1. 试用期结束后，系统会弹出"激活授权"提示框
  2. 在提示框中复制您的"设备识别码"（每台设备唯一）
  3. 切换到本页面"购买激活码"Tab，按步骤生成订单号
  4. 扫码加客服微信，发送订单号 + 设备识别码 + 诊所信息
  5. 付款后客服通过云端管理后台生成对应的"授权激活码"
  6. 将激活码粘贴到激活提示框中，点击"激活"按钮
  7. 激活成功后即可无限制使用（各版本功能差异见"版本对比"）
☁️云端版账户开通流程
  1. 先下载离线版体验功能，确认满足需求
  2. 将诊所名称 + 管理员账号 + 管理员姓名 + 联系方式发送给开发者
  3. 开发者通过平台管理后台创建诊所和账户
  4. 开发者将账户信息回传给您
  5. 下载云端版 APP/桌面版 或 直接访问云端网页版
  6. 使用收到的账户信息登录即可使用
