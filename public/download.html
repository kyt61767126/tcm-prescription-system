📋 安装说明 Android · Windows · 激活流程
📱Android APP 安装步骤
  1. 下载对应版本的 APK 文件到手机
  2. 在手机设置中允许"安装未知来源应用"（设置 → 安全 → 未知来源）
  3. 点击下载的 APK 文件进行安装
  4. 安装完成后打开 APP，使用上方"默认账号"登录（如 admin/admin）
  5. 首次使用有 7 天试用期（限 30 张处方），到期后需输入授权激活码
  6. 登录后请立即到"设置"中修改默认密码，确保账户安全
  7. 如遇"安装包损坏"提示，请重新下载并核对 SHA-256 校验值
💻Windows 桌面版安装步骤
  1. 下载安装版 exe 文件（推荐）或便携版
  2. 双击运行安装程序，按提示完成安装
  3. 安装完成后从桌面快捷方式启动
  4. 便携版无需安装，解压后直接运行 exe 即可
  5. 使用上方"默认账号"登录（如 admin/admin）
  6. 首次使用有 7 天试用期（限 30 张处方），到期后需输入授权激活码
  7. 登录后请立即到"设置"中修改默认密码，确保账户安全
🔑激活流程（试用到期后）
  1. 试用期结束后，系统会弹出"激活授权"提示框
  2. 在提示框中复制您的"设备识别码"（每台设备唯一）
  3. 切换到本页面"购买激活码"Tab，按步骤生成订单号
  4. 扫码加客服微信，发送订单号 + 设备识别码 + 诊所信息
  5. 付款后客服通过云端管理后台生成对应的"授权激活码"
  6. 将激活码粘贴到激活提示框中，点击"激活"按钮
  7. 激活成功后即可无限制使用（各版本功能差异见"版本对比"）
☁️云端版账户开通流程
  1. 先下载离线版体验功能，确认满足需求
  2. 将诊所名称 + 管理员账号 + 管理员姓名 + 联系方式发送给开发者
  3. 开发者通过平台管理后台创建诊所和账户
  4. 开发者将账户信息回传给您
  5. 下载云端版 APP/桌面版 或 直接访问云端网页版
  6. 使用收到的账户信息登录即可使用

🔒 如何确认下载的文件是官方正版？ ▼
每个版本卡片下方都显示该安装包的 SHA-256 校验值。下载完成后请计算文件哈希值并与页面显示的值比对：
Windows：certutil -hashfile 文件名 SHA256
Mac/Linux：shasum -a 256 文件名
两者完全一致则文件完整无损，否则请重新下载。
📱 APK 安装时提示"安装包损坏"怎么办？ ▼
请按以下步骤排查：
1. 重新下载 APK 文件（可能下载不完整）
2. 核对 SHA-256 校验值是否与页面一致
3. 确认手机已开启"允许安装未知来源应用"
4. 关闭手机安全软件的"安装拦截"功能后重试
5. 如仍无法解决，请联系客服微信（hktzy1688）获取帮助
💾 数据安全吗？会不会丢失？ ▼
离线版：数据完全存储在本地设备，不会上传云端。请定期使用"设置 → 数据备份"导出数据到安全位置。
云端版：数据云端+本地双存储，实时同步，多设备共享。
建议：无论哪个版本，都建议定期备份重要数据。
