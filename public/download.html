安装说明
Android APP 安装步骤
  1. 下载对应版本的 APK 文件到手机
  2. 在手机设置中允许"安装未知来源应用"（设置 → 安全 → 未知来源）
  3. 点击下载的 APK 文件进行安装
  4. 安装完成后打开 APP，使用上方"默认账号"登录（如 admin/admin）
  5. 首次使用有 7 天试用期（限 30 张处方），到期后需输入授权激活码
  6. 登录后请立即到"设置"中修改默认密码，确保账户安全
  7. 如遇"安装包损坏"提示，请重新下载并核对 SHA-256 校验值
Windows 桌面版安装步骤
  1. 下载安装版 exe 文件（推荐）或便携版
  2. 双击运行安装程序，按提示完成安装
  3. 安装完成后从桌面快捷方式启动
  4. 便携版无需安装，解压后直接运行 exe 即可
  5. 使用上方"默认账号"登录（如 admin/admin）
  6. 首次使用有 7 天试用期（限 30 张处方），到期后需输入授权激活码
  7. 登录后请立即到"设置"中修改默认密码，确保账户安全
激活流程（试用到期后）
  1. 试用期结束后，系统会弹出"激活授权"提示框
  2. 在提示框中复制您的"设备识别码"（每台设备唯一）
  3. 将设备识别码 + 诊所名称 + 联系方式发送给开发者
  4. 开发者通过云端管理后台生成对应的"授权激活码"
  5. 将激活码粘贴到激活提示框中，点击"激活"按钮
  6. 激活成功后即可无限制使用（个人版/专业版功能差异见下方版本对比）
云端版账户开通流程
  1. 先下载离线版体验功能，确认满足需求
  2. 将诊所名称 + 管理员账号 + 管理员姓名 + 联系方式发送给开发者
  3. 开发者通过平台管理后台创建诊所和账户
  4. 开发者将账户信息回传给您
  5. 下载云端版 APP/桌面版 或 直接访问云端网页版
  6. 使用收到的账户信息登录即可使用
如何校验文件完整性（SHA-256）
Windows certutil -hashfile 文件名 SHA256
Mac/Linux shasum -a 256 文件名

将计算结果与上方页面的 SHA-256 值比对，完全一致则文件完整无损。
