打包机如何接入（局域网/本机脚本） 
1) Cloudflare Pages 环境变量配置 BUILD_QUEUE_TOKEN（随机长字符串）。
2) 打包机轮询认领（PowerShell 示例）：
   $h = @{ 'X-Build-Token' = $env:BUILD_QUEUE_TOKEN; 'Content-Type' = 'application/json' }
   $r = Invoke-RestMethod -Method Post -Uri 'https://tcm-prescription-system.pages.dev/api/build-queue' `
        -Headers $h -Body '{"action":"claim"}'
   $r.task   # 为空表示队列空
3) 打包完成后回执：
   $body = @{ action='update'; taskId=$r.task.id; status='success'; version='2026.11.17-1';
              sha256='<64位十六进制>'; sizeBytes=12345678;
              downloadUrl='https://.../file.exe'; message='打包完成' } | ConvertTo-Json
   Invoke-RestMethod -Method Post -Uri 'https://tcm-prescription-system.pages.dev/api/build-queue' `
        -Headers $h -Body $body
4) 失败回执：status='failed'，message 写失败原因；后台可点「重试」重新入队。
