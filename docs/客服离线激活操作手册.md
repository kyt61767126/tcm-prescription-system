## 一、产品现状速知（回答客户前必读）

客服每天被问到的问题，统一按以下口径回答（与官网下载页一致）：

1. **账号制，没有默认账号**：软件首次启动需注册开通，**手机号即账号**，由客户本人设置密码。不存在 `admin/admin` 之类的出厂账号，客户说"默认账号密码是多少"时，引导其用本机注册窗口注册。
2. **三种使用形态（同一个安装包，不用单独下载）**：
   - **7 天免费试用**：注册后自动开始，功能同标准版；
   - **永久免费版**：在激活窗口点【免费使用】联网领取一次，**本机永久有效、开方不限数量**，之后可完全离线使用；限制：数据备份/恢复/自动备份、Excel/CSV 导入导出、拍照录像、**语音录入**为标准版功能，免费版打印处方带「惠康中医免费版」水印；
   - **付费版**：输入激活码激活（标准版 / 机构版；云端另有云端个人版 / 云端机构版），免费版日后输入激活码即可升级，**数据全部保留**。
3. **语音录入不单独卖**：**任一付费版均含语音功能，无需单独购买、无需加购**。客户问"语音版多少钱"时，告知买任意付费版即自带。
4. **设备计数**：付费版每台设备单独激活（桌面端与手机端算不同设备）：标准版一码限 1 台，桌面+手机需分别购买；机构版一码 3-5 台、双端无需重复购买（以激活码实际档位为准）。
5. **统一客服微信号：`hktzy1688`**（全产品唯一客服微信，旧号 huikang-tcm 已停用）。

## 二、客服工作台（日常办公首选入口）

### 2.1 登录

- 地址：<https://tcm-prescription-system.pages.dev/admin/service.html>
- 用管理员分配的 **service 客服账号**登录（客服账号由管理员在「客服账号」Tab 创建，只能用用户名登录、不能用手机号注册）。
- 登录状态保存在当前浏览器，换电脑需重新登录；**不要在公共电脑勾选记住密码**。

### 2.2 七个 Tab 与能力边界

| Tab | 能做什么 |
|---|---|
| **工单审批** | 查看客户提交的激活工单；通过（系统自动发码+开云端账号）或驳回；处理中状态会锁定，防双击双发 |
| **离线激活** | 为断网客户生成 `license.dat`（本手册第三章） |
| **授权查询** | 按激活码/用户名/诊所名/机器码查授权状态、类型、设备数、到期日（只读） |
| **设备解绑** | 按完整机器码查版本绑定、解绑设备（解绑后该机器可重新激活任意版本） |
| **账号诊断** | 按手机号/用户名/机器码查账号锁定、墓碑、登录失败等状态（排障用） |
| **客户全景** | 输入手机号/用户名/机器码一键聚合客户的账号、授权码、设备、工单、订单等全部分区（接待客户先查这里） |
| **客服账号** | 仅管理员可见，客服看不到此 Tab |

**客服能做的**：工单审批通过/驳回、离线发码、授权与设备查询、设备解绑、账号诊断、客户全景查询。

**客服不能做的（操作会返回 403，需联系管理员）**：生成/批量生成激活码、激活码延期、手动改状态、停用/删除激活码或账号、云端账号相关的高危管理、订单确认收款、客服账号的创建/改密/停用。

> 所有写操作（审批、发码、解绑）均有平台审计日志：记录操作人、IP、时间，事后可追溯。请确保每一步都由客户本人发起并核验身份。

## 三、离线激活文件生成（客户机器断网时）

### 3.1 客户需提供的 3 项信息

引导客户从软件激活窗口复制，**逐项核对后再操作**：

| 信息 | 说明 | 常见错误 |
|---|---|---|
| **激活码** | `BNZC-XXXX-XXXX-XXXX-XXXX`（无 I/O/0/1 易混字符） | 少字符、带空格 |
| **机器码（机器 ID）** | **8-64 位英文、数字、下划线或连字符**。不同端长度不同，**不要要求客户必须凑满 32 位**——复制完整即可 | 发成中文诊所名、手动抄写漏字符 |
| **诊所名** | 激活码已绑定诊所时**必填**，须与绑定名完全一致（含全角字符、标点） | 同音字、简写 |

满额码换机时还需要第 4 项：**联系人用户名**（见 3.4）。

### 3.2 方式 A：工作台「离线激活」Tab（推荐）

1. 登录客服工作台 → 打开【离线激活】Tab；
2. 填写激活码、机器码；激活码已绑诊所则填诊所名；
3. 点击【生成并下载 license.dat】——浏览器自动下载文件（文件名形如 `license_诊所名_机器码前8位_日期.dat`）；
4. 页面回显授权信息（用户/版本/诊所/到期），**核对诊所名与版本无误**；
5. 将文件通过微信/邮件发给客户（传输注意事项见 5.5）；
6. 指导客户按第四章导入。

### 3.3 方式 B：一键脚本（工作台无法使用时的备用通道）

适用于浏览器不可用等场景，由管理员预先在客服电脑配置一次：

1. 管理员将客服密钥（64 位十六进制）保存为 `%USERPROFILE%\.hktzy\license-export-secret.txt`；
2. 双击仓库根目录的 **`start-license.bat`**（实际调用 `generate-license.ps1`）；
3. 按窗口提示仅修改脚本【2】区段的 3 个客户信息（激活码/机器码/诊所名），保存后双击启动；
4. 成功后 `license.dat` 自动出现在桌面，窗口打印授权信息供核对。

**密钥铁律**：
- 密钥只存在于客服本机 `.hktzy` 文件中，**严禁粘贴进脚本正文、聊天窗口、文档、邮件**；
- 严禁外传密钥文件；客服离职/换电脑时通知管理员轮换密钥；
- v1.0 手册中的 curl/Postman 手工拼请求方式已废弃，**不要再用**（密钥会留在命令历史与截图里）。

### 3.4 满额换机的特殊规则（重点）

激活码设备数已达上限、又要在新机器激活时：

- **同机重装/重激活**（机器码不变）：直接生成，不占新设备配额，无需联系人；
- **换新机器**（机器码变了、设备满额）：服务端会解绑该码**最旧的一台设备**为新机腾位；通过工作台（service 账号）操作时**必须填写「联系人」**，且必须与激活码登记的用户名**完全一致**——这是防恶意踢机的身份闸：
  - 先在线下核验客户身份（如让客户用登记手机号/微信联系），再按登记用户名填写；
  - 联系人留空、与登记不符、或该码无登记用户时，请求会被拒绝（错误文案见第五章），后两种情况转管理员处理；
  - 旧机器不会立即锁死，但下次联网验证时会检测到已被解绑。

### 3.5 频控（遇到 429 不是故障）

- 工作台（service 账号）：**每 IP 20 次/小时 + 每账号 30 次/小时 + 同一激活码 10 次/小时**，三重独立计数；
- 脚本密钥通道：每 IP 20 次/小时；
- 客服日常一单一次，正常用不会触限；触限后等待整点滚动恢复，**不要反复点按钮**。

## 四、客户侧导入步骤（发给客户照做）

1. 在激活窗口找到黄色按钮【📁 导入离线激活文件】；
2. 点击后选择客服发来的 `.dat` 文件（微信传成 `.txt` 的先改回 `.dat`）；
3. 弹窗显示授权信息（用户/版本/诊所/到期），**核对诊所名正确**；
4. 点击【确定】，提示「✅ 激活成功」后软件自动重启；
5. 重启后即为对应付费版本。免费版不需要本流程（激活窗口点【免费使用】即可）。

## 五、常见错误与处理

### 5.1 生成时接口返回的错误

| 错误信息 | 原因 | 处理 |
|---|---|---|
| `需要平台员工权限（管理员/客服）或有效的 LICENSE_EXPORT_SECRET`（403） | 未登录/登录失效，或脚本密钥错误、被管理员置空 | 工作台重新登录；脚本通道联系管理员核对密钥文件 |
| `请提供激活码（code）` / `请提供机器 ID`（400） | 字段漏填 | 补齐后重试 |
| `机器码格式无效（需 8-64 位英文、数字、下划线或连字符）`（400） | 机器码复制错（常见误发中文诊所名） | 让客户重新点【复制】整段发来 |
| `激活码格式错误，应为 BNZC-XXXX-XXXX-XXXX-XXXX`（400） | 激活码残缺/带空格 | 整码重新复制 |
| `激活码不存在`（404） | 码输错或未生成 | 用【授权查询】核实；查无此码联系管理员 |
| `激活码已被禁用，请联系管理员`（403） | 码被停用 | 转管理员启用，客服无权启用 |
| `激活码已过期`（403） | 已到期 | 转管理员延期，客服无权延期 |
| `此激活码已绑定诊所，必须提供 clinicName`（400） | 未填诊所名 | 向客户索取激活窗口显示的完整诊所名 |
| `诊所名与激活码绑定的诊所不一致（绑定：X，输入：Y）`（403） | 诊所名不符 | 让客户复制完整名称，注意全角/半角/标点 |
| `客服换机必须填写与授权登记一致的联系人用户名`（403） | 满额换机未填联系人 | 线下核验客户身份后填登记用户名（见 3.4） |
| `联系人与授权登记用户不一致`（403） | 联系人填错 | 核对登记用户名；无法确认转管理员 |
| `该授权缺少登记用户，无法完成客服换机，请联系管理员处理`（403） | 码上无登记用户 | 转管理员用管理员通道处理 |
| `操作过于频繁（每小时限 20 次）…` 等 429 | 触达频控 | 等待恢复，不要连点（见 3.5） |

### 5.2 客户导入时报错

| 现象 | 原因 | 处理 |
|---|---|---|
| 「激活文件与本机不匹配」 | 文件不是为该客户机器生成的 | 核对机器码是否与客户本次提供的一致，重新生成 |
| 「授权文件写入权限不足」 | 软件装在 Program Files 等受保护目录 | 让客户右键软件图标【以管理员身份运行】后重新导入 |
| 微信收不到 `.dat` / 文件打不开 | 微信拦截后缀 | 发送时改后缀 `.txt`，客户保存后改回 `.dat`；或打 zip 包；邮件无此限制 |

## 六、安全与操作规范

1. **身份核验先行**：发码、换机、解绑前，确认对面是码主本人（建议用登记手机号/微信 `hktzy1688` 侧核实），不认"客户转述"。
2. **客服账号专人专用**：不得借人；发现泄露立即通知管理员改密（改密后旧登录全部失效）。
3. **密钥三不**：脚本密钥不粘贴、不截图、不外传；只存本机 `.hktzy` 文件。
4. **一码一机**：每个 license.dat 只对生成时的那台机器有效。
5. **激活码状态变化**：成功发码后码变为 `used`；同机重激活不重复占额；满额换机会留 `auto-unbind` 日志、被拒换机留 `unbind-denied` 日志。
6. **全程留痕**：审批/发码/解绑均记录操作人、IP、时间，平台审计可查。
7. **文件传输**：优先微信文件/邮件；改 `.txt` 后缀后务必提醒客户改回 `.dat`。

## 八、附录

### 8.1 接口（供了解，日常无需手工调用）

- 地址：`POST https://tcm-prescription-system.pages.dev/api/license/export-license`
- 三种鉴权：① 工作台 service 账号 Bearer（自动携带）；② 管理员 Bearer；③ 请求头 `X-Export-Secret`（脚本备用，密钥可被管理员置空以关闭该通道）。
- 请求参数：

| 字段 | 必填 | 说明 |
|---|---|---|
| `code` | 是 | 激活码 `BNZC-XXXX-XXXX-XXXX-XXXX` |
| `machineId` | 是 | 客户机器码，8-64 位英文/数字/下划线/连字符 |
| `clinicName` | 条件必填 | 激活码已绑定诊所时必填，须与绑定名一致，不含 `\|`，≤100 字符 |
| `user` | 换机必填 | 联系人用户名；service 通道满额换机时必传且须与登记用户一致 |

- 响应：`success`、`license`（base64，保存为 .dat 的内容）、`licenseInfo`（user/type/issuedAt/expiresAt/maxPrescriptions/features/clinicName/maxDevices/devicesCount，供核对）、`fileName`（建议文件名）、失败时 `error`。
- `licenseInfo.type` 常见值：`standard`（标准版）、`institution`（机构版）、`cloud_personal`（云端个人版）、`cloud_clinic`（云端机构版）、`free`（免费版）。
