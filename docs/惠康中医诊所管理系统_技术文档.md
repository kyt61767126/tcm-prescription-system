## 一、项目概述

### 1.1 项目简介

惠康中医诊所管理系统是一套面向中医诊所的信息化管理平台，涵盖处方开具、药品管理、病例管理、验方设置、统计分析、拍照录像、数据备份等核心功能。系统采用云端与离线双架构设计，支持网页端、桌面端（Windows）、移动端（Android）三端运行，满足不同场景下的使用需求。

### 1.2 应用场景

- **云端版本**：面向多诊所连锁运营，支持平台总管理员统一管控、处方监管、跨诊所数据汇总
- **离线版本**：面向单诊所独立运营，无需互联网即可运行，数据本地存储，保障隐私安全
- **个人版本**：面向个体中医师，简化功能，专注处方开具

### 1.3 系统构成总览

系统共包含 **8 个应用**，分为云端和离线两大类：

| 分类 | 版本名称 | 运行平台 | 技术框架 | 版本号 |

## 四、功能特点详细说明

### 4.1 处方管理

**功能描述：** 中医处方的开具、保存、查阅、导出。

**使用说明：**
1. 在处方页面录入患者信息（姓名、性别、年龄、门诊号）
2. 通过药品搜索框搜索中药，设置用量（克），添加到处方
3. 录入诊断、治法、用法、剂数等信息
4. 支持调用验方（预设方剂）快速开方
5. 点击"保存处方"按钮保存到处方历史
6. 支持处方预览（模拟纸质处方样式）
7. 支持处方导出为图片（PNG 格式）
8. 历史处方按时间倒序排列（最新处方排在最上面）

**技术实现：**
- 处方数据结构：JSON（患者信息 + 药品列表 + 诊断信息 + 时间戳）
- 云端存储：Cloudflare KV（key: prescription:{clinicId}:{prescriptionId}）
- 离线存储：IndexedDB（prescriptions 表）
- 处方编号：自动生成（日期 + 序号）

### 4.2 药品管理

**功能描述：** 中药饮片的增删改查、价格管理、搜索。

**使用说明：**
1. 点击"药品管理"按钮打开药品管理弹窗
2. 支持按药品名称、拼音首字母搜索
3. 添加新药品：名称、规格、单价、采购价
4. 编辑现有药品信息
5. 删除药品（需确认）
6. 云端版本支持平台统一药品库管理

**技术实现：**
- 药品数据结构：JSON（id + 名称 + 拼音 + 规格 + 单价 + 采购价）
- 云端存储：Cloudflare KV（key: medicines:{clinicId}）
- 离线存储：IndexedDB（medicines 表）
- 搜索：前端实时模糊匹配

### 4.3 病例管理

**功能描述：** 患者病例信息的管理和查阅。

**使用说明：**
1. 点击"病例管理"按钮打开病例管理弹窗
2. 录入患者病例信息
3. 支持关联历史处方
4. 支持病例查阅和搜索

### 4.4 验方设置

**功能描述：** 预设常用方剂（验方），开方时可快速调用。

**使用说明：**
1. 点击"验方设置"按钮打开验方管理弹窗
2. 创建新验方：名称 + 药品列表 + 用量
3. 编辑现有验方
4. 删除验方
5. 开处方时，可选择验方快速填充药品列表

**技术实现：**
- 验方数据结构：JSON（id + 名称 + 药品列表）
- 云端存储：Cloudflare KV（key: formulas:{clinicId}）
- 离线存储：IndexedDB（formulas 表）

### 4.5 统计分析

**功能描述：** 处方数据统计和药材使用分析。

**使用说明：**
1. 点击"统计"按钮打开统计分析弹窗
2. 选择统计范围（时间区间）
3. 查看月度统计报表（处方数量、金额汇总）
4. 查看药材使用统计 Top 10（柱状图）
5. 支持患者就诊列表查看

**技术实现：**
- 前端图表：CSS 柱状图（无第三方图表库）
- 统计数据：从处方数据中聚合计算
- 表格响应式：固定边框内显示，不超出屏幕

### 4.6 账户管理

**功能描述：** 用户账户的创建、管理、权限控制。

**使用说明：**
1. 管理员可通过账户管理创建/删除用户
2. 三级角色体系：
   - `platform_admin`（平台总管理员）：全平台管控权限
   - `clinic_admin`（诊所管理员）：本诊所管理权限
   - `doctor`（医师）：处方开具权限
3. 修改密码功能

### 4.7 平台管理（仅云端版本）

**功能描述：** 多诊所统一管控（仅平台总管理员可用）。

**使用说明：**
1. 平台总管理员登录后显示"平台管理"按钮
2. 查看所有诊所列表
3. 查看各诊所统计数据
4. 管理平台统一药品库

### 4.8 处方监管（仅云端版本）

**功能描述：** 全平台处方汇总查看（仅平台总管理员可用）。

**使用说明：**
1. 平台总管理员可查看全平台所有处方
2. 支持按诊所、时间筛选
3. 处方监管弹窗显示汇总数据

### 4.9 拍照录像

**功能描述：** 处方相关的舌象照片、面诊照片、诊疗视频的拍摄和管理。

**使用说明：**
1. 在处方页面点击拍照/录像按钮
2. 支持 4 种媒体类型：
   - 舌面图像（tongue_front）
   - 舌下络脉（tongue_under）
   - 面诊照片（photo）
   - 诊疗视频（video）
3. 拍照录像完成后自动关联到处方记录
4. 点击查看按钮打开媒体查看器
5. 媒体查看器支持：
   - 单文件轮播显示（一次显示一个文件）
   - 滚轮/双指缩放（0.2x ~ 8x）
   - 拖动平移
   - 双击重置
   - 左右切换按钮
   - 底部缩略图导航条
   - 视频内联播放

**文件存储路径：**

| 平台 | 类型 | 存储路径 |
|------|------|---------|
| Android 10+ | 图片 | `内部存储/Android/data/<包名>/files/Pictures/惠康中医处方/YYYY-MM/` |
| Android 10+ | 视频 | `内部存储/Android/data/<包名>/files/Movies/惠康中医处方/YYYY-MM/` |
| Android 9- | 图片 | `内部存储/Pictures/惠康中医处方/YYYY-MM/` |

**文件命名规则：**
- 排列顺序：处方签图片 → 面诊照片 → 诊疗视频
- 命名格式：`患者姓名_处方编号_type.ext`
- 图片格式：PNG
- 视频格式：WebM

**技术实现：**
- Electron 桌面端：`MediaRecorder API` + `getUserMedia API` + `video-recorder.js`
- Android APP：Java Camera API + `MediaRecorder` + NativeBridge
- 权限处理：Electron 主进程 `setPermissionRequestHandler` + Android `ActivityCompat.requestPermissions`
- 云端 APP 拍照录像文件存放手机本地存储，不上云端存储

### 4.10 数据备份与恢复

**功能描述：** 处方、药品、验方数据的导出备份和导入恢复。

**使用说明：**
1. 点击"数据备份"按钮，将数据导出为 JSON 文件
2. 点击"数据恢复"按钮，选择 JSON 备份文件恢复数据
3. 云端版本：通过 Cloudflare KV API 备份/恢复
4. 离线版本：通过 IndexedDB 导出/导入
5. 移动端 APP 基本设置隐藏备份/恢复/清除按钮

**技术实现：**
- 备份格式：JSON（包含所有处方、药品、验方数据）
- 云端备份：`functions/api/backup-kv.js` + `functions/api/restore-kv.js`
- 离线备份：IndexedDB → JSON 文件下载

### 4.11 处方导出

**功能描述：** 将处方导出为图片，可打印或分享。

**使用说明：**

2. 系统生成处方图片（PNG 格式）

## 五、安全特性

### 5.1 身份认证

- **密码哈希**：SHA-256(salt + ':' + password)，每个用户独立 salt
- **Token 认证**：HMAC-SHA256 无状态 token
- **认证模块**：`functions/api/_lib/auth.js`
- **登录安全**：Trae 永远需要输入用户名和密码登录，即使记住用户名也必须手动输入密码

### 5.2 权限控制

- **三级角色体系**：
  - `platform_admin`（平台总管理员）
  - `clinic_admin`（诊所管理员）
  - `doctor`（医师）
- **功能级权限**：根据角色显示/隐藏功能按钮（处方查阅、平台管理、处方监管）
- **数据级权限**：诊所管理员只能管理本诊所数据

### 5.3 数据安全

- **XSS 防护**：`escapeHtml` 函数转义用户输入
- **HTTPS 传输**：Cloudflare 自动 HTTPS 证书
- **Electron 安全**：
  - `contextIsolation: true`（上下文隔离）
  - `nodeIntegration: false`（禁用 Node.js 集成）
  - `preload.js` 安全暴露 API
- **离线数据**：本地 IndexedDB 存储，不上传云端

### 5.4 APP 安全

- **诊所名和医生名只读**：APP 运行时不允许修改
- **Android 权限最小化**：仅申请必要权限（相机、存储）

## 八、整体更新优化建议

### 8.1 当前架构优化建议

#### 8.1.1 代码结构优化
- **问题**：public/index.html 单文件 512KB，包含所有 HTML/CSS/JS，维护困难
- **建议**：逐步拆分为模块化文件（CSS 外部文件、JS 模块化），但需保持 Cloudflare Pages 兼容
- **优先级**：中（功能稳定后再重构）

#### 8.1.2 版本管理优化
- **问题**：8 个应用共用核心代码，修改需同步 6+ 个 HTML 文件
- **建议**：建立代码生成脚本，从模板自动生成各版本 HTML 文件
- **优先级**：高（减少维护成本和出错率）

#### 8.1.3 数据库优化
- **问题**：云端使用 Cloudflare KV（键值存储），复杂查询需前端处理
- **建议**：考虑迁移到 Cloudflare D1（SQLite），支持 SQL 查询
- **优先级**：中（数据量增大后有必要）

### 8.2 功能优化建议
