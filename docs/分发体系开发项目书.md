3. **自动更新**：Electron autoUpdater + 云端版本检查

#### 2.1.3 技术实现方案

### 2.2 授权码系统（云端生成激活码）

#### 2.2.1 业务流程

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  管理员后台  │────→│  生成激活码   │────→│  发送给用户  │
└─────────────┘     └─────────────┘     └─────────────┘
                                                │
                                                ▼
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  软件激活    │←────│  用户输入码  │←────│  用户收到码  │
└─────────────┘     └─────────────┘     └─────────────┘
       │
       ▼
┌─────────────┐
│  云端校验    │
│  生成license │
└─────────────┘
```

#### 2.2.2 激活码格式

**格式**：`BNZC-XXXX-XXXX-XXXX-XXXX`（16 位，4-4-4-4 分组）

**示例**：`BNZC-A1B2-C3D4-E5F6-G7H8`

**字符集**：`ABCDEFGHJKLMNPQRSTUVWXYZ23456789`（去除易混淆字符 0/O/1/I）

**生成规则**：
- 前 4 位固定 `BNZC`（品牌标识）
- 后 16 位随机生成
- 云端数据库记录：激活码、版本类型、有效期、绑定机器ID、使用状态

#### 2.2.3 技术架构

**云端（Cloudflare Pages Functions）**：
```
/api/license/generate    - 管理员生成激活码
/api/license/validate    - 软件激活时校验激活码
/api/license/status      - 查询激活码状态
```

**客户端（Electron）**：
- 新增"激活"界面：输入激活码 → 调用云端校验 → 生成 license.dat
- 离线激活：用户输入激活码后，软件用内置公钥验证签名

**数据库（Cloudflare D1 / KV）**：
```sql
CREATE TABLE licenses (
  code TEXT PRIMARY KEY,           -- 激活码
  user TEXT,                       -- 用户名
  type TEXT,                       -- trial/personal/pro
  days INTEGER,                    -- 有效天数
  issued_at TEXT,                  -- 签发时间
  activated_at TEXT,               -- 激活时间
  machine_id TEXT,                 -- 绑定机器ID
  status TEXT DEFAULT 'unused',    -- unused/used/expired
  signature TEXT                   -- 签名（防伪造）
);
```

### 2.3 自动更新（Electron autoUpdater）

#### 2.3.1 更新流程

```
软件启动 → 检查云端版本 → 有新版？
                         │
                    ┌────┴────┐
                    │         │
                   是         否
                    │         │
                    ▼         ▼
              下载更新包    正常启动
                    │
                    ▼
              安装并重启
```

#### 2.3.2 技术方案

**云端版本清单**（`https://your-domain.com/updates/latest.json`）：
```json
{
  "version": "1.0.1",
  "releaseDate": "2026-08-01",
  "releaseNotes": "修复xxx问题，新增xxx功能",
  "url": "https://your-domain.com/updates/惠康中医-个人-Setup-1.0.1.exe",
  "hash": "sha256-hash-value"
}
```

**客户端配置**（main.js）：
```javascript
const { autoUpdater } = require('electron-updater');

autoUpdater.setFeedURL({
  provider: 'generic',
  url: 'https://your-domain.com/updates/'
});

app.whenReady().then(() => {
  autoUpdater.checkForUpdatesAndNotify();
});

autoUpdater.on('update-available', () => {
  dialog.showMessageBox({
    type: 'info',
    title: '发现新版本',
    message: '检测到新版本，是否立即更新？',
    buttons: ['立即更新', '稍后提醒']
  });
});
```

**更新策略**：
- 启动时静默检查（不弹窗）
- 有更新时右下角提示
- 用户可选择立即更新或稍后提醒
- 下载完成后提示重启安装

### 3.2 数据流

#### 3.2.1 激活流程数据流

```
用户输入激活码
    │
    ▼
客户端组装请求 {code, machineId}
    │
    ▼
POST /api/license/validate
    │
    ▼
云端校验：激活码存在？未使用？未过期？
    │
    ├─ 校验失败 → 返回错误信息
    │
    └─ 校验成功 → 生成 license 内容（含签名）
                    │
                    ▼
              返回 license base64
                    │
                    ▼
              客户端写入 license.dat
                    │
                    ▼
              提示激活成功，重启软件
```

#### 3.2.2 版本检查数据流

```
软件启动
    │
    ▼
GET /updates/latest.json
    │
    ▼
比较版本号 version > currentVersion ?
    │
    ├─ 否 → 正常启动
    │
    └─ 是 → 提示用户更新
              │
              ▼
        下载 exe 安装包
              │
              ▼
        校验 SHA256 哈希
              │
              ▼
        安装并重启
```

## 六、风险评估

### 6.1 技术风险

| 风险 | 概率 | 影响 | 应对措施 |
|---|:---:|:---:|---|
| Cloudflare D1 限额 | 中 | 中 | 单库 5GB 足够，激活码数据量小 |
| 激活码被暴力破解 | 低 | 高 | 限制每 IP 每小时 5 次校验请求 |
| 离线激活公钥泄露 | 低 | 高 | 公钥泄露不影响安全（私钥才关键） |
| 自动更新失败 | 中 | 中 | 保留手动下载备用方案 |
| 用户机器 ID 变化 | 中 | 低 | 允许 1 次解绑重激活 |

### 6.2 业务风险

| 风险 | 概率 | 影响 | 应对措施 |
|---|:---:|:---:|---|
| 试用版被绕过 | 中 | 中 | 处方计数器加密存储 + 云端校验 |
| 激活码被分享 | 高 | 中 | 绑定机器 ID，1 码 1 机 |
| 用户拒绝更新 | 中 | 低 | 更新提示友好，不强制更新 |

### 6.3 安全风险

| 风险 | 概率 | 影响 | 应对措施 |
|---|:---:|:---:|---|
| license.dat 被复制传播 | 高 | 中 | 绑定机器 ID（后续实施） |
| asar 被解包逆向 | 中 | 高 | asarmor + 代码混淆 |
| 云端 API 被攻击 | 低 | 高 | Cloudflare WAF + 速率限制 |
