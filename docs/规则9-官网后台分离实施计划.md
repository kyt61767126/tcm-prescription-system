> 日期：2026-08-08
> 适用范围：惠康中医管理系统所有部署形态
> 状态：**方案文档化**（本次 1→4 顺序修复中，规则9 不改动代码/部署，避免引发路由冲突；下次迭代按此文档执行）

---

## 1. 背景与目标

根据用户规则 9 硬性规定：

> 官网、后台两个独立网站分开，
> 官网只下载安装包，
> 后台用来生成激活码、审批工单。

当前项目中，`public/` 目录同时存在：
- 官网下载页（`download.html`）
- 云端 APP 主入口（`index.html` + 相关前端资源）
- 管理后台目录（`admin/`）

三者共享域名、共享静态资源目录，违背「独立网站」要求，也存在以下风险：
1. 安全边界不清晰：官网访客可探测 `/admin/` 目录；
2. 版本耦合：后台升级时可能破坏官网下载页，反之亦然；
3. 审计困难：官网访问日志与后台操作日志混杂。

**目标**：将 3 类流量物理拆分为 2 个独立站点（官网 + 后台），云端 APP 归入后台域（因为云端 APP 本身就是授权后的业务入口）。

---

## 2. 拆分后架构

| 站点 | 用途 | 示例域名 | 部署目录 | 对外暴露 |
|---|---|---|---|---|
| **官网站** | 仅承载产品介绍、下载安装包、版本公告（纯展示只读） | `https://www.huikangzy.com` | `site-official/` | 公网所有人可访问 |
| **后台&云端APP站** | 管理后台（激活码、工单审批、版本管理）+ 云端用户登录开方（带鉴权） | `https://admin.huikangzy.com` | `site-admin/` | 公网但需登录；后台子路径可加 IP 白名单 |

> 备注：
> - 「云端 APP」和「后台」放在同一域下是合理的，因为两者都需要账号体系，都会调用 `/api/license/*` / `/api/prescription/*` 等同一组后端接口；
> - 仅「官网」需要严格隔离（不执行任何登录态，不调用敏感 API，只有静态页面 + 下载链接跳转到 OSS/CDN）。

### 部署约束（强约束，下次必须遵守）
1. **site-official 不能包含：** `auth-core.js` / `permission.js` / `admin/` / 任何 `localStorage` 登录态逻辑 / 任何写入型后端接口调用；
2. **site-official 只能：** 展示 HTML、图片、版本号文字、`<a>` 直链 OSS/CDN 的 `.exe/.apk` 下载；
3. **site-admin 必须：** 所有 `/admin/*` 路由前加鉴权中间件（后台管理员账号独立于诊所管理员账号，属于平台管理员 role=`platform_admin`）。

## 4. Nginx / Cloudflare 路由配置示例（下一迭代执行）

### 4.1 Nginx（自托管）
```nginx
# 官网：www.huikangzy.com
server {
    listen 443 ssl http2;
    server_name www.huikangzy.com;
    root /var/www/kyt-zy/site-official;
    index index.html download.html;

    # 绝对禁止访问后台路径
    location ^~ /admin/ { return 404; }
    location ^~ /api/   { return 404; }

    # 安装包下载文件类型放行（大文件推荐 X-Accel-Redirect 到 OSS）
    location ~* \.(exe|apk|zip|msi)$ {
        expires 7d;
        add_header Cache-Control "public, immutable";
    }
}

# 后台+云端APP：admin.huikangzy.com
server {
    listen 443 ssl http2;
    server_name admin.huikangzy.com;
    root /var/www/kyt-zy/site-admin;

    # 云端APP入口
    location / {
        try_files $uri $uri/ /index.html;
    }

    # /admin/ 路径加平台管理员鉴权
    location ^~ /admin/ {
        # auth_request /_platform_admin_check;   ← 按实际平台鉴权网关配置
        try_files $uri $uri/ /admin/index.html;
        # 可选：IP 白名单（仅办公室固定 IP 能访问后台）
        # allow 1.2.3.4/32; deny all;
    }

    # /api/ 反向代理到业务服务（license/工单/处方...）
    location ^~ /api/ {
        proxy_pass https://backend.huikangzy.internal;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 4.2 Cloudflare Pages（当前使用 `tcm-prescription-system.pages.dev`）
建议拆成两个 Pages 项目：
| 项目名 | 绑定域名 | 构建输出目录 |
|---|---|---|
| `huikang-official` | `www.huikangzy.com` | `site-official/` |
| `huikang-admin` | `admin.huikangzy.com` | `site-admin/` |

通过 Workers 限制：`huikang-official` 项目中 Worker 拦截任何 `/admin` `/api` 路径返回 404。

## 5. 与现有规则的联动

| 规则 | 联动点 | 说明 |
|---|---|---|
| 规则1（4版本） | 官网下载页版本按钮只显示 YB/YJ/LB/LJ 四个 | download.html 上按钮文案对应四版本标签；APK/EXE 文件名也对应 `惠康中医-{YB,YJ,LB,LJ}-{version}-{platform}.{ext}` |
| 规则3（激活工单） | 工单在「后台」审批、生成激活码 | `ticket-approval.html` 展示客户提交的工单（machineId 只显示哈希前后 6 位，避免泄露完整哈希给后台操作员）；一键通过后调用 `/api/license/activate-from-ticket` 写入激活码并发邮件/短信 |
| 规则5（登录约束） | 后台平台管理员使用独立账号体系 | 不和诊所 admin/clinic_admin 混用；强密码 + 双因子推荐 |
| 规则6（媒体不上云） | 官网站点目录绝对不写入舌脉照 | 通过 `.gitignore` + `deploy-ignore` 双重保护；上传权限仅限 OSS/CDN 发布流水线 |
