## 二、角色模型

### 离线版角色（offline / clinic_custom / personal）

| 角色 | 值 | 权限 |
|------|---|------|
| 管理员 | `admin` | 用户管理、修改密码、开机自启、查看所有处方 |
| 普通用户 | `user` | 修改密码、查看自己的处方 |

### 云端版角色（cloud）

| 角色 | 值 | 权限 |
|------|---|------|
| 平台总管理员 | `platform_admin` | 平台管理、处方监管、药品管理 |
| 诊所管理员 | `clinic_admin` | 用户管理、修改密码、开机自启、药品管理、处方查阅 |
| 医师 | `doctor` | 修改密码、查看自己的处方 |

### 角色映射关系

| 离线版 | 云端版 | 等价权限 |
|--------|--------|---------|
| `admin` | `clinic_admin` | 诊所级管理员 |
| `user` | `doctor` | 普通医师 |
| - | `platform_admin` | 平台级管理员（仅云端） |

## 三、统一权限判断函数

### 3.1 AuthCore 中的角色判断（shared/auth-core.js）

```javascript
// 是否为管理员（含所有管理员类型）
function isAdmin(user) {
    return user.role === 'admin' || user.role === 'clinic_admin' || user.role === 'platform_admin';
}

// 是否为诊所管理员（离线admin + 云端clinic_admin）
function isClinicAdmin(user) {
    return user.role === 'admin' || user.role === 'clinic_admin';
}

// 是否为平台管理员（仅云端）
function isPlatformAdmin(user) {
    return user.role === 'platform_admin';
}
```

### 3.2 Permission 中的复合权限判断（shared/permission.js）

```javascript
// 是否可以管理用户（管理员 + 非个人版）
canManageUsersByRole(user)

// 是否可以修改密码（所有登录用户）
canChangePassword(user)

// 是否显示账户管理按钮
shouldShowUserManage(user)    // = canManageUsersByRole(user)

// 是否显示修改密码按钮
shouldShowChangePwd(user)     // = canChangePassword(user)

// 是否显示开机自启选项（诊所管理员 + 非个人版）
shouldShowAutoStart(user)

// 是否可以查看所有处方（诊所管理员）
canViewAllPrescriptions(user)
```

## 五、各端实现规范

### updateUserDisplay 函数（统一模板）

```javascript
function updateUserDisplay() {
    if (currentUser) {
        document.getElementById('userDisplayName').textContent = currentUser.name;
        const userManageBtn = document.getElementById('userManageBtn');
        const changePwdBtn = document.getElementById('changePwdBtn');
        const mobileUserManageBtn = document.getElementById('mobileUserManageBtn');
        const mobileChangePwdBtn = document.getElementById('mobileChangePwdBtn');
        const autoStartSection = document.getElementById('autoStartSection');

        const canManage = (window.Permission && Permission.shouldShowUserManage)
            ? Permission.shouldShowUserManage(currentUser)
            : (currentUser.role === 'admin' || currentUser.role === 'clinic_admin');
        const canChangePwd = (window.Permission && Permission.shouldShowChangePwd)
            ? Permission.shouldShowChangePwd(currentUser)
            : true;
        const canAutoStart = (window.Permission && Permission.shouldShowAutoStart)
            ? Permission.shouldShowAutoStart(currentUser)
            : (currentUser.role === 'admin' || currentUser.role === 'clinic_admin');

        if (userManageBtn) userManageBtn.style.display = canManage ? 'block' : 'none';
        if (changePwdBtn) changePwdBtn.style.display = canChangePwd ? 'block' : 'none';
        if (mobileUserManageBtn) mobileUserManageBtn.style.display = canManage ? 'inline-flex' : 'none';
        if (mobileChangePwdBtn) mobileChangePwdBtn.style.display = canChangePwd ? 'inline-flex' : 'none';
        if (autoStartSection) autoStartSection.style.display = canAutoStart ? 'block' : 'none';
    }
}
```

### showUserManageModal 权限拦截（统一模板）

```javascript
function showUserManageModal() {
    if (!currentUser) return;
    const canManage = (window.Permission && Permission.shouldShowUserManage)
        ? Permission.shouldShowUserManage(currentUser)
        : (currentUser.role === 'admin' || currentUser.role === 'clinic_admin');
    if (!canManage) {
        alert('只有管理员可以管理用户');
        return;
    }
    // ... 业务逻辑
}
```

## 六、修改密码功能规范

### 密码强度评估

| 强度 | 条件 | 颜色 |
|------|------|------|
| 弱 | 长度<6 或 仅满足1项 | #f44336 (红) |
| 中 | 满足2-3项 | #ff9800 (橙) |
| 强 | 满足4-5项 | #4CAF50 (绿) |

评估项：长度≥6、长度≥10、大小写混合、含数字、含特殊字符

### 密码验证规则

1. 原密码、新密码、确认密码均不能为空
2. 新密码长度 ≥ 6位
3. 新密码与确认密码必须一致
4. 原密码必须正确（哈希比对）

## 九、开发规范

1. **禁止直接使用 `role === 'admin'` 字符串比较**，必须通过 Permission 模块判断
2. **新增功能按钮时**，在 permission.js 中添加对应的 shouldShow 方法
3. **新增角色时**，在 auth-core.js 的 isAdmin/isClinicAdmin 中添加支持
4. **修改 updateUserDisplay 时**，遵循统一模板，使用 Permission 判断
5. **权限相关修改**，更新本文档的权限矩阵和修复记录
